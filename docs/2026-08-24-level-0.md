# 2026-08-24 — Level 0

## Goal

Prove that YouthLM can depend on a provider-neutral model boundary and can test
model behavior without AWS.

## Deliberately included

- `ModelProvider` protocol
- Normalized request and response models
- Deterministic `FakeModelProvider`
- Tests for the happy path and bounded failures

## Deliberately excluded

- Bedrock implementation
- Agent loop
- Module and edge contracts
- Data tools
- RAG
- AgentCore production entrypoint

## Invariants to review

1. The agent core will depend on `ModelProvider`, never directly on boto3.
2. Every provider returns the same `ModelTurn` shape.
3. Fake behavior is scripted and fails explicitly when exhausted.
4. Contract models reject unknown fields.

## Success gate

```bash
uv run pytest
uv run ruff check .
```

Both commands must pass before adding `BedrockConverseProvider`.

The tests are also compatible with the standard-library runner:

```bash
python -m unittest discover -s tests -v
```
